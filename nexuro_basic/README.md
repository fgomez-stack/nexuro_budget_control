# Nexuro Budget Control

Control detallado de presupuestos por departamento con trazabilidad de gastos y archivos adjuntos.

## Características
* Gestión de presupuestos anuales o mensuales.
* Registro de líneas de gasto detalladas.
* Cálculo automático de monto gastado y saldo restante.
* **Soporte para adjuntar facturas y cotizaciones en PDF.**
* Seguridad por grupos de usuario.

## Instalación
1. Copie la carpeta `nexuro_basic` en su directorio de addons.
2. Actualice la lista de aplicaciones en Odoo.
3. Instale el módulo `Nexuro Budget Control`.
